# 小苗总 & Chloe 💕

我们的情侣纪念网页

## 在线访问

部署后访问: https://your-username.vercel.app

## 本地预览

```bash
# 方法1: 直接用浏览器打开
open index.html

# 方法2: 用本地服务器
npx serve .
```

## 部署到 Vercel

1. 把这个文件夹推送到 GitHub 仓库
2. 登录 [vercel.com](https://vercel.com)
3. 点击 "New Project" → Import from GitHub
4. 选择你的仓库
5. 点击 Deploy

部署成功后，Vercel 会给你一个 `.vercel.app` 链接，国内可以正常访问~

## 自定义内容

编辑 `index.html` 中的：
- 纪念日日期（第 318 行：`new Date('2026-03-18')`）
- 时间线故事文字和照片
- 相册照片
- 问答题目
